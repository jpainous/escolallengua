📘 Manual d'ús

Fitxa de redacció — guia ràpida

1 Què és i com començar

La fitxa serveix perquè l'alumne esquematitzi i redacti un text a partir d'una imatge.

🖼️ 1. Tria una escena

Al desplegable de dalt, selecciona la imatge que vols descriure. Apareixerà a sota.

🧠 2. Esquematitza

Tria el tipus de text (narració, poema, notícia…) i omple els blocs amb idees curtes. Tens un botó ℹ️ al costat per veure com funciona aquell tipus.

📝 3. Redacta

Escriu el text final. El comptador de paraules s'actualitza sol. El vocabulari que hagis triat a l'esquema et surt recordat a sota.

💾
Tot es guarda sol. Si tanques la pàgina i la tornes a obrir, el text segueix allà. Veuràs un avís verd "Guardat" a baix a la dreta cada cop que es desa.

2 Les seccions de la fitxa

Cada secció es pot obrir o tancar clicant la seva capçalera de color.

Secció Per a què serveix
✅ Rúbrica Repassar que el text compleix els requisits abans de lliurar-lo.
🧑‍🎓 Dades de l'alumne Nom, curs i data. Sortiran al document final.
🧠 Esquematitza Organitzar les idees abans d'escriure.
📝 Redacta Escriure el text definitiu.
🔽
Si vols veure-ho tot alhora, clica Obre-ho tot a baix. Si vols centrar-te en una secció, clica'n la capçalera per tancar les altres.
🌙
A dalt a la dreta tens un botó per canviar entre mode clar i mode fosc. Tria el que et vagi millor per llegir.

3 Exportar i imprimir

Tres maneres de conservar la feina feta.

🖨️ Imprimeix

Obre el diàleg d'impressió del navegador. Les capçaleres surten en color si la impressora és a color. També pots triar "Desa com a PDF" per tenir una còpia digital.

📄 Exporta .docx

Crea un fitxer Word editable amb la imatge incrustada, l'esquema, la rúbrica i la redacció. Es pot obrir amb Word, Google Docs o LibreOffice.

🌐 Exporta .html

Crea un fitxer web autocontingut: conté el text i la imatge dins del mateix fitxer. Ideal per enviar per correu o arxivar. S'obre amb qualsevol navegador.

📅
Els fitxers porten la data al nom: Anna_Ferrer_El_gol_20261005.docx
Carpeta d'exemple: 📁 La meva carpeta ├── redaccio.html ├── llista.json ├── red_01.jpg ├── Anna_El_gol_20261005.docx └── Anna_El_gol_20261005.html

4 Problemes comuns

Què fer si alguna cosa no funciona.

❓ No apareix cap escena al desplegable
  • Comprova que el fitxer llista.json és a la mateixa carpeta que l'HTML.
  • Si obres l'HTML amb doble clic (file://), el navegador pot bloquejar-lo. Obre'l amb Live Server o un servidor local.
❓ La imatge no surt al fitxer exportat
  • Passa quan obres l'HTML amb doble clic per seguretat del navegador.
  • Solució: obre l'HTML amb Live Server (VS Code) o amb python -m http.server.
❓ He canviat de tema i no es veu bé
  • Refresca la pàgina amb Ctrl + F5 per assegurar que es carrega la versió nova.
🔧
Si alguna cosa falla, obre la consola del navegador amb F12 i mira si hi ha cap missatge vermell. Sovint el mateix missatge ja diu què passa.
